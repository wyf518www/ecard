数字名片 · 使用说明（广监云品牌版 · 全公司多名片微官网）
====================================================

配色体系（已内置，无需修改）
  主色 · 科技蓝  #0044E6   —— 交互图标、按钮、Tab 激活态
  辅助色 · 青蓝  #20C4C4   —— 点击状态、小点缀、渐变条
  文字 · 深灰    #1A1A1A / #666666    背景 · 白色

文件结构
  list.html      ★ 名片墙（公司入口页：全员头像墙、按部门分组、可搜索）
  card.html      名片展示页（不用动），?id=xxx 指定某人
  s/             ★ 微信分享预览页目录（每人一个 工号.html，工具自动生成）
  company.js     ★ 公司级信息（LOGO/地址/官网/业务/视频，改一处全员生效）
  cards.js       ★ 人员名片数据（手动改 或 用工具生成，见下）
  make-cards.html★ 名片数据生成器（Excel 表 → cards.js + 分享页）
  photos/        ★ 人员图片目录（头像 / 微信二维码都放这里）
  _qrcode.min.js 二维码生成库（不用动）
  index.html     旧版单人页（仅作备份保留）
  广监云.png     公司 LOGO（放根目录）
  Dockerfile / nginx.conf / docker-compose.yml   Docker 部署三件套

网址结构（部署后）
  https://你的域名/                  → 名片墙（全公司入口，对外只发这一个链接）
  https://你的域名/card.html?id=xxx  → 某人的名片（xxx 是名片 id）
  https://你的域名/s/工号.html       → 某人的微信分享链接（卡片预览带本人照片，
                                       打开后显示预览，点击底部进入完整名片页）
  https://你的域名/make-cards.html  → 名片数据生成器（内部维护用）

【一、全公司名片上线流程（行政自助）】
  1. 维护者打开 make-cards.html，点「下载 Excel 模板」，发给行政
  2. 行政在 Excel 里填写全公司人员（一人一行），表头别改、列顺序可乱
     必填：姓名；其余可留空（ID 留空会按手机号自动生成）
     头像/二维码列填图片文件名，对应图片文件放进 photos/ 文件夹
  3. 填好后：Excel 里框选全部数据（含表头）→ Ctrl+C 复制
     → 打开 make-cards.html 粘贴 → 预览确认 → 「下载 cards.js」
     （Excel「另存为 CSV」上传的方式也支持，中文编码自动识别）
  4. 再点「下载微信分享预览页」，把下载的一批 工号.html 全部放入 s/ 文件夹
     （浏览器询问"允许下载多个文件"时点允许）
  5. 用下载的 cards.js 覆盖项目里的同名文件，图片拷入 photos/
  6. 重新部署（见第五节），名片墙和个人名片即时更新
  注：重新生成只覆盖人员数据，company.js 里的公司信息不受影响；
      表里"访问数"留空时会自动沿用线上旧值。

【二、少量增删改（直接手动改 cards.js 也可以）】
  · CARDS 数组里每个 { } 块就是一张名片，复制一块改内容即可
  · id 是名片的唯一标识，网址为 card.html?id=名字
  · 部门字段 dept 决定名片墙的分组（同部门的人挨着放即可）
  · 手动新增名片后若也要微信卡片预览，重新跑一遍工具生成 s/ 页，
    或参照 s/ 里现有文件复制一份改标题/照片/姓名/职位/电话/名片 id

【三、公司信息、地图、访问数】
  公司信息   → company.js（公司名/LOGO/地址/官网/业务/视频）
  地图坐标   → company.js 的 COMPANY.map（高德坐标拾取器
               lbs.amap.com/tools/picker，按 经度,纬度 填写）
  访问数     → 名片底部「已有 N 位客户访问」当前为静态展示数字，
               在 cards.js 各名片的 visitCount 字段（或表格"访问数"列）
  核心业务   → company.js 的 companyIntro + services
  企业视频   → company.js 的 video.url 换正式 mp4 链接
  预约洽谈   → 当前为前端演示（无后端）。接后端时在
               card.html 脚本中搜 appt-form 的 submit 处理

【四、替换图片】
  公司 LOGO → 覆盖根目录 广监云.png
  人员头像 / 微信二维码 → 文件放进 photos/，cards.js 该名片的
              avatar / wechatQR 填 ./photos/文件名（表格里只填
              文件名即可，生成器会自动加前缀）；留空则头像自动
              生成姓名首字渐变、二维码显示占位提示
  注意：头像照片建议 ≥300×300 像素（微信分享卡片的缩略图取自它，
        太小可能不被抓取，会回退显示公司 LOGO）

【五、Docker 部署】
  cd 项目目录
  docker compose up -d --build     # 访问 http://服务器IP:8080/
  改 cards.js / s/ / photos/ 后重新执行上面命令即可生效
  正式上线：域名 + ICP备案 + HTTPS（微信内打开未备案域名会被拦截/提示）
  nginx 已配置兜底：s/ 里不存在的工号.html 会自动 302 跳回名片页，
  分享链接永不 404

【六、微信分享与卡片预览（照片 + 简略信息）】
  微信转发链接的卡片样式 = 标题(title) + 两行灰色描述(meta description)
  + 右侧小缩略图(页面第一张图)。本方案已实现"每人卡片不同"：

  ▶ 分享链接用这个（推荐）：名片页点「分享名片」→ 复制/二维码里的
    链接就是 https://域名/s/工号.html，微信卡片自动显示：
      标题：姓名 · 职位｜公司
      描述：公司｜电话 186 xxxx xxxx｜一句话简介
      缩略图：本人照片（无照片时为公司 LOGO）
    打开链接 → 展示本人预览卡，可直接拨号，或点击底部查看完整名片
  ▶ 名片墙链接（https://域名/）转发时卡片显示公司 LOGO + 公司名

  两个注意：
  1) 微信对同一链接的卡片信息有缓存（几小时~几天）。人事信息更新
     重新部署后，旧卡片可能仍显示旧内容，属正常现象，新用户/过几天
     自动刷新；急的话可以在跳转链接上把工号后缀改掉重新生成。
  2) 微信抓取规则是非公开的黑盒，以上为各网站通行做法、大概率生效；
     若某天缩略图/描述不显示，最稳的兜底是「方案 1 发卡片图」。

  方案 1 · 发横版卡片图（内容 100% 可控）
    打开个人名片 → 点「分享名片」→「保存卡片图片」→ 发给好友/群
    → 对方长按识别图上二维码 → 打开名片预览，点击底部查看完整名片
    （卡片图上的二维码同样指向 s/工号.html，识别后再转发卡片预览不变）

【七、进阶：公众号 JS-SDK（100% 精确控制卡片）】
  微信对未接入 JS-SDK 的链接按上述规则自动抓取。要完全自定义
  （描述必显、缩略图任选、不受缓存影响），需要：
  1. 域名 + 备案 + 部署（已有 Docker 方案）
  2. 注册并认证微信公众号（服务号），配置 JS-SDK 安全域名
  3. 加一个签名小后端 + 页面引入 wx.config 自定义分享标题/图/描述
  —— 日常使用建议先用第六节方案，效果稳定且零资质要求
