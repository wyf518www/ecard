数字名片 · 使用说明（广监云品牌版 · 多名片微官网）
====================================================

配色体系（已内置，无需修改）
  主色 · 科技蓝  #0044E6   —— 交互图标、按钮、Tab 激活态
  辅助色 · 青蓝  #20C4C4   —— 点击状态、小点缀、渐变条
  文字 · 深灰    #1A1A1A / #666666    背景 · 白色

文件结构
  card.html      名片展示页（不用动）
  cards.js       ★ 名片数据（所有名片的姓名/电话/头像等都在这里改）
  _qrcode.min.js 二维码生成库（不用动）
  index.html     旧版单页（仅作备份保留，正式使用 card.html）
  广监云.png     公司 LOGO
  赵允.jpg       头像示例
  微信二维码.jpg 微信二维码示例
  Dockerfile / nginx.conf / docker-compose.yml   Docker 部署三件套

【一、多名片管理（唯一修改入口：cards.js）】
打开 cards.js（记事本即可）：
  · CARDS 数组里每个 { } 块就是一张名片
  · 新增名片：复制一个 { } 块，改掉内容即可，互不影响
  · id 是名片的唯一标识，网址为 card.html?id=名字
    例：id 为 zhaoyun → 访问 card.html?id=zhaoyun
    （不带 ?id= 时默认显示第一张名片）
  · COMPANY 是公司公共信息（LOGO/地址/官网/业务/视频），
    所有名片共享，改一处全员生效

【二、微信推送两步走】
方案 1 · 发横版卡片图（推荐，内容 100% 可控）
  1. 打开名片页，点底部「分享名片」按钮
  2. 弹窗中是自动生成的横版卡片图：
     头像 + 公司 + 职位 + 电话 + 名片二维码
  3. 点「保存卡片图片」，把图片发给微信好友/群
  4. 对方长按识别图上二维码 → 直接打开你的数字名片
方案 2 · 直接转发链接
  1. 弹窗中点「复制」复制名片专属链接
  2. 微信里粘贴发送。对方点开先看到横版小卡片预览
     （标题=姓名·职位｜公司，缩略图=广监云LOGO），
     点进去才是完整数字名片
  注意：链接分享的预览卡片由微信自动抓取，
     完全自定义需部署后配置公众号 JS-SDK（见第六节）

【三、其他信息修改】
  地图坐标   → cards.js 的 COMPANY.map（高德坐标拾取器
               lbs.amap.com/tools/picker，按 经度,纬度 填写）
  访问数据   → 各名片的 visitCount 字段
  核心业务   → COMPANY.companyIntro + COMPANY.services
  企业视频   → COMPANY.video.url 换正式 mp4 链接
  预约洽谈   → 当前为前端演示（无后端）。接后端时在
               card.html 脚本中搜 appt-form 的 submit 处理

【四、替换图片】
  公司 LOGO → 覆盖 广监云.png
  头像      → 把头像图放进文件夹，在 cards.js 该名片
              avatar 字段填路径；留空自动生成姓名首字渐变头像
  微信二维码 → 把二维码图放进文件夹，填 wechatQR 字段

【五、Docker 部署】
  cd 电子名片
  docker compose up -d --build     # 访问 http://服务器IP:8080/card.html
  改 cards.js 增删名片后重新执行上面命令即可生效

【六、进阶：完全自定义微信分享卡片】
  微信对未接入 JS-SDK 的链接，分享卡片标题取页面 <title>、
  缩略图取页面第一张图——本页已优化为「姓名·职位｜公司 + LOGO」。
  要 100% 精确控制（含电话显示），需要：
  1. 域名 + 备案 + 部署（Docker 或静态托管）
  2. 注册微信公众号，做 JS-SDK 安全域名配置
  3. 引入 wx.config 自定义分享标题/图/描述
  —— 日常使用建议直接用「方案 1 发卡片图」，效果最好最稳
